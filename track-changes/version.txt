track-changes v6.0.1 — Quarto whole-region bug fixes (patch; no grammar change, backward-compatible, no document migration, suite stays at 6 hooks). (1) The PreToolUse analyzer no longer falsely blocks a `.tc-region` whose body contains Quarto BRACE-LESS shorthand fenced divs (`::: statement`, `::: result-box`, `::: example-end`): `grammar.py`'s fenced-div opener regex now recognizes BOTH the brace-block `{…}` and the bare-class-identifier forms, so an inner brace-less closing `:::` no longer pops the enclosing region early (it was reported as "added content not wrapped"). (2) The region styling in `reference/tc-clean.css` now binds under Quarto: Pandoc renders fenced-div key–value attributes as `data-`-prefixed HTML attributes (`data-tc-n`, `data-tc-prov`), so the selectors now target BOTH the data- and raw forms — the margin `[N]` number and the imported-provenance color appear instead of silently breaking. (3) `SKILL.md` §12 documents the `data-*` attribute behavior, that a region (unlike inline `<mark>`) needs the CSS included to be visible at all, and the purge-safe `include-in-header: text:` `<style>` path for wiring the region CSS into a Quarto project (theme SCSS can purge rules for unknown classes; a raw header `<style>` survives). Adds regression test TC-W-13.
