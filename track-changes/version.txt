8.2.0
2026-07-12
track-changes v8.2.0 — import-fidelity coverage check for verified-import.
- COVERAGE GATE: a verified import can no longer silently drop source content (the recurring
  "translated only part of a slide" failure, e.g. dropping r_f of four rates). New shared lib
  tc_core/coverage.py compares CONTENT TOKENS (words >=4 letters minus stoplist, numbers >=2
  significant chars, subscripted ids like r_f) with formatting normalized away — reformatting
  passes, dropped content blocks (hook exit 2, missing tokens named, pending import preserved
  for a corrected retry). Fail-closed when the source cannot be re-read at write time.
- OVERRIDE: /tc import --allow-partial stores allow_partial on the pending record; the hook
  then lands the write and records the override + dropped list in the audit entry.
- AUDIT: new /tc coverage <doc> <source> [--units N,N,...] reports per-unit % covered and
  missing tokens (--slides accepted as alias); exit non-zero on any drop.
- Additive and backward-compatible: optional pending-record key; import behavior otherwise
  unchanged; no new hooks (suite stays at 6); no document migration.

8.1.0
2026-07-12
track-changes v8.1.0 — committed-content invariant + transcript provenance.
- RESOLUTION GATE: accept/reject/accept-all/reject-all now REFUSE (exit 3) if the target
  file has uncommitted changes or is untracked (tc_require_clean in lib/tc-cli.sh). An open
  mark is editable right up to resolution, so approval could otherwise attach to content the
  reviewer never read (observed live: an AI polish correction applied and accepted in one
  step). Enforced sequence: commit instructor tweaks (own commit) -> commit AI corrections
  as MARKED edits (own commit) -> review diffs -> resolve. list is not gated; TC_FORCE=1 is
  a human-only override; fail-open outside a git repo. No new hooks; suite stays at 6.
- PROVENANCE (v7 work, first published here): tc-prov="transcript" joins authored/imported
  in tc_core/grammar.py PROV_VALUES — AI wording over the instructor's own class-recording
  transcript content; conventionally paired with a TEMPORARY .tc-verbatim scaffolding block
  (delete after confirming). Documented in SKILL.md (Provenance, Fix E extended) + digest.
- Mark grammar note (from the same incident): the <s>OLD</s> form cannot re-present an
  already-applied change for approval (OLD must still exist in the file) — the rule is that
  polish corrections are marked BEFORE resolution, never applied during it.
