track-changes v3: two-skill split. A narrowed always-on track-changes (mark-tracking only) plus a new opt-in verified-import skill (/import) for inserting a vetted source into a tracked document; the two share one tc_core package. SessionStart now injects a ~2.9 KB digest instead of the full SKILL.md (~93% smaller, under the inline cap), with the full doc lazy-loaded on demand. The persistent daemon was dropped after measurement (in-process is fast enough). The v2 source-provenance import wrappers, cross-file mark renumbering, and edit-inside-non-rendering-construct sibling were removed; in-construct edits now route to /draft. /import verifies the AI-converted block is content-faithful to the named source and lets a verified import land clean (no marks); a discrepancy blocks fail-closed. Mechanical fixes #4-#7 (working-file default, /tc menu, no orphan blank line, no deprecation warning). Clean break: the v3 mark grammar is unchanged, so existing tracked documents need no conversion. v3.0.1 patch: `/tc mark` on a non-directory argument is now a hard error (no marker written) instead of silently writing a broken marker, matching `/tc migrate`. 329/329 tests pass.
