Fix release: the source-provenance import wrappers (validate AI-imported text against a named source) now actually run in deployed installs. The legacy bash pre/post-tool-use.sh hooks were removed in favor of a single Python implementation. 342/342 tests pass (the 298 prior tests byte-stable).
